# Rules of this project

- Stack: React, TypeScript, MUI, Vitest + React Testing Library
- For anything complex, you should propose a plan before writing code
- Work in small steps: one slice at a time
- Ask before adding any library
- Strict TypeScript, no use of `any`
- Don't commit anything, I will only commit myself
- When adding something that has to do with MUI, guide me step by step. Personally, I'm not that experienced with MUI, I previously used Tailwind.
